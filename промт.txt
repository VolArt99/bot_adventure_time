# Промт проекта: Bot Adventure Time (детализированный)

Рабочий контекст для разработчика/агента. Цель: быстро понять архитектуру, правила и ожидания по качеству.

---

## Роль и цель

Ты — senior Python/aiogram инженер, который:
1. Поддерживает стабильность прод-бота на VDS (Docker Compose + PostgreSQL).
2. Вносит улучшения без поломки пользовательских сценариев.
3. Сохраняет документацию в актуальном состоянии.

Definition of Done:
- код работает;
- `pytest -q` зелёный;
- обновлены `README.md`, `промт.txt` и при необходимости `deploy/VDS_SETUP.md`;
- пользовательские тексты — через `bot/utils/design.py`, не хардкод в handlers.

---

## Продуктовый контекст

Бот для приватного Telegram-сообщества (супергруппа с Topics / форум).
Задачи: мероприятия, участие, напоминания, дайджесты, random 1:1, онбординг, split bill, пожертвования на поддержку бота.

### Пользовательские потоки
1. `/start` → онбординг → одобрение владельцем (`approve_user_*`) → invite-ссылка → вход в группу → запись в `approved_members`.
2. Участник **в Telegram-группе без одобрения бота** не получает команды участника (авто-добавление в `approved_members` отключено).
3. `/create_event` в ЛС → превью → публикация карточки в тему; push подписчикам категории; `/edit_event` — правка полей.
4. Участники: `✅ В путь!` / `⏳ В резерве` / `❌ В другой раз`; `🚗 Ищу попутку`; подтверждение участия за 24 ч до события.
5. Напоминания (APScheduler) + weekly digest + restore jobs после рестарта.
6. `/my_events` → «📋 Копия #ID» — шаблон из прошлого мероприятия.
7. `/donate` — ссылки на сборы (доступно и не-участникам).
8. Админы: отчёты, темы, random-пары, sync members, контроль «Рассказа о себе».

## Технологии

- Python 3.10+
- aiogram 3.x
- PostgreSQL 16 (asyncpg pool)
- APScheduler
- Docker Compose, long polling (`python -m bot.main`)
- Опционально: OpenWeatherMap (`WEATHER_API_KEY`)

**Не используется:** YDB, Cloud Functions, webhook entrypoint, таблица `reminder_jobs`.

## Актуальные UX-детали

- Кнопки карточки: `✅ В путь!`, `⏳ В резерве`, `❌ В другой раз`, `🚗 Ищу попутку`
- За `ATTENDANCE_CONFIRM_HOURS` (по умолчанию 24) до события — ЛС «всё ещё иду» с кнопками confirm/decline
- `/my_events`: «📋 Копия #ID» → мастер создания с предзаполнением
- Превью: кнопка `🗺️ Публикуем!`
- `/menu`: сезонная шапка, слоган «Куда отправимся сегодня?»; `/help` и кнопки меню синхронизированы с `commands.py`
- Карточка мероприятия: **Hero + детали** (без дублирования категорий/цены); погода в день события; блок карпулинга с ride_seeker
- Быстрые шаблоны: выбор «оставить из шаблона» / «ввести своё» для названия и описания
- Мастер событий: «↩️ Назад» на шагах темы, категорий и превью
- Split-bill: `money_collection_line` + чек-лист ✅/⏳ + «🔔 Напомнить должникам»
- `/donate` в разделе «Помощь» меню + команда; outsider: `start,donate`
- `@username` в admin-командах — резолв через БД + approved members
- `/send_event_card` — короткое сообщение со ссылкой, не дубль карточки
- `/send_events_list`, `/digest`, `/my_digest` — учитывают `period_end` (активный период); ссылки `t.me/c/<chat>/<thread>/<msg>` для Topics
- `/random_pairs` — общая карточка в topic, без ЛС участникам
- FSM в ЛС: `answer_private_intermediate` / `answer_private_final`
- Callback policy: `CALLBACK_DELETE_WIZARD_MESSAGE` только для wizard
- ЛС-уведомления откладываются в тихие часы (`QUIET_HOURS_START`–`QUIET_HOURS_END`)

## Роли и доступ

- **Owner** — полный доступ (`OWNER_ID`)
- **Admin** — расширенный, с лимитами (`ADMIN_IDS`)
- **Approved member** — запись в `approved_members` (после `approve_user_*` или уже существующая); пользовательские команды из `MEMBER_ALLOWED_COMMANDS`
- **Outsider** — `start`, `donate` (по умолчанию)

**Не путать:** членство в Telegram-группе ≠ approved member. Авто-upsert при вступлении в группу отключён.

Центр для ЛС: `middleware/command_access.py` + `config.py` + `bot/commands.py`
Групповые callback: проверки в хендлерах (`@approved_member_callback_only`, `_can_manage_event`, `_can_view_event`).

Дневные лимиты в PostgreSQL (`user_command_usage_daily`), действуют на команды и callback в ЛС.

## Правила разработки

1. Не ломать совместимость команд без migration-плана.
2. SQL только параметризованный (asyncpg).
3. HTML — `html.escape()` для пользовательского ввода (события, split bill, админ-ответы).
4. Callback `data` — `parse_callback_suffix_int` / `parse_callback_split_int`, не голый `int(split(...))`.
5. HTTP — timeout + exception handling.
6. Бизнес-логику не дублировать — shared/services/utils.
7. Новый домен БД — отдельный модуль в `bot/db/`, экспорт через `bot/db/__init__.py`.
8. Нетривиальные сценарии — тест (`test_security_helpers.py`, `test_access_and_flows.py`).
9. Изменил UX → `design.py` + help + README + промт + тесты.
10. Новые фразы — в `BRAND_VOICE`, не в handlers.
11. Не коммитить секреты (.env, токены).
12. Групповые callback — явная проверка прав; не полагаться на `CommandAccessMiddleware`.

## Деплой (VDS)

См. `deploy/VDS_SETUP.md` и раздел README «Деплой на VDS».

Кратко:
```bash
cp .env.example .env
# BOT_TOKEN, GROUP_ID, OWNER_ID, POSTGRES_PASSWORD, DONATION_* ...
docker compose up -d --build
docker compose ps   # health: postgres + bot
```

PostgreSQL: `deploy/postgresql.vds.conf` + `deploy/pg_hba.docker.conf`, лимит 768M. Бот: 512M. **Не публиковать** 5432 на хост.

Бэкапы:
```bash
./deploy/backup_db.sh   # chmod 600 на .sql.gz и .sha256
./deploy/verify_backup.sh backups/adventure_time_*.sql.gz
./deploy/restore_db.sh backups/adventure_time_*.sql.gz   # осознанный откат
```
Cron-пример: `deploy/backup-cron.example`, retention: `BACKUP_RETENTION_DAYS`. Дамп содержит PII — хранить с ограниченным доступом.

## Частые ошибки

1. **FSM завис** — onboarding_guard, middleware, state filters
2. **Не публикуется в тему** — права бота, `message_thread_id`, GROUP_ID
3. **Нет данных в БД** — DATABASE_URL / PG*, postgres healthy, AUTO_INIT_DB
4. **Команда недоступна** — allowlist, `approved_members`, лимиты (в т.ч. callback в ЛС)
5. **В группе, но бот не пускает** — нет записи в `approved_members`; нужен `approve_user_*`
6. **/donate без кнопок** — не заданы DONATION_SBERBANK_URL / DONATION_TBANK_URL
7. **Тексты разъехались** — забыли обновить `design.py` и help
8. **iOS: ссылка на карточку открывает группу** — в `build_event_message_link` нужен `thread_id` темы; перепубликовать афишу после фикса
9. **bot unhealthy** — heartbeat не обновляется; смотреть `docker compose logs bot`, `BOT_HEARTBEAT_PATH`
10. **ImportError из bot.database** — символ не в `bot/db/__init__.py` `__all__`
11. **Резерв сдвинулся без отказа** — проверить `decline_*`: `move_from_waitlist` только если `remove_participant` вернул True
